# FLUX Dev 1 Krea Prompting Guide

## Model Overview
FLUX Dev 1 Krea is an advanced variant of the FLUX model optimized for creative and artistic generation with enhanced control over style and composition. It excels at maintaining consistency while offering flexible creative direction.

## Token Limit
- **Maximum tokens**: 300
- **Optimal range**: 150-250 tokens
- **Format**: Structured natural language with style markers

## Core Principles

### Key Elements
1. **Hierarchical description**: Main subject → Details → Context
2. **Style consistency**: Unified artistic direction throughout
3. **Creative enhancement**: Artistic interpretation over literal description
4. **Mood coherence**: Emotional and atmospheric consistency
5. **Technical precision**: Clear rendering and quality specifications

## Prompt Structure

### Essential Formula
```
[Primary Subject] + [Artistic Style] + [Environmental Context] + [Mood/Atmosphere] + [Technical Specifications] + [Creative Modifiers]
```

### Building Blocks

#### 1. Primary Subject Definition
Start with the most important element:
- **Core identity**: What it is fundamentally
- **Distinguishing features**: Unique characteristics
- **State or action**: Static or dynamic presentation
- **Proportions**: Size relationships

Example:
```
A celestial warrior with crystalline armor reflecting nebula patterns, floating weightlessly
```

#### 2. Artistic Style Layer
Define the creative interpretation:
- **Art medium**: Digital painting, concept art, illustration
- **Aesthetic movement**: Surrealism, art deco, cyberpunk
- **Color philosophy**: Palette, temperature, saturation
- **Texture approach**: Smooth, rough, mixed media

Example:
```
rendered in ethereal digital art style with watercolor textures blending into sharp geometric patterns
```

#### 3. Environmental Context
Build the world around the subject:
- **Space definition**: Interior, exterior, abstract
- **Scale indicators**: Relative size markers
- **Atmospheric elements**: Fog, particles, light beams
- **Supporting objects**: Context-giving elements

Example:
```
surrounded by floating crystal shards in a vast cosmic void with distant galaxies spiraling
```

#### 4. Mood and Atmosphere
Emotional and sensory qualities:
- **Emotional tone**: Mysterious, triumphant, melancholic
- **Sensory details**: Temperature, texture, sound implications
- **Narrative hints**: Story elements without explicit description
- **Temporal feeling**: Moment in time, era, season

Example:
```
emanating ancient wisdom and serene power, timeless presence suggesting eons of existence
```

#### 5. Technical Specifications
Rendering and quality details:
- **View angle**: Perspective and framing
- **Focus technique**: Depth of field, focal points
- **Lighting setup**: Sources, intensity, color
- **Quality markers**: Resolution, detail level

Example:
```
cinematic wide-angle view with selective focus, rim lighting creating ethereal glow, 8K detail with subsurface scattering
```

#### 6. Creative Modifiers
Unique artistic touches:
- **Stylistic fusion**: Combining different art styles
- **Unexpected elements**: Surreal or creative additions
- **Visual metaphors**: Symbolic representations
- **Artistic techniques**: Special effects or methods

Example:
```
with reality fragmenting at edges like shattered glass, colors bleeding between dimensions
```

## Advanced Techniques

### Style Fusion
Combine multiple artistic styles coherently:
```
Baroque ornamental details merging with minimalist geometric forms, creating harmonious contrast between complexity and simplicity
```

### Emotional Gradients
Create mood transitions within the image:
```
transitioning from warm, hopeful dawn colors at top to cool, mysterious twilight hues below
```

### Narrative Layering
Embed story without explicit description:
```
ancient ruins partially reclaimed by bioluminescent vegetation, suggesting civilization's transformation rather than decay
```

### Dimensional Play
Work with space and perspective creatively:
```
impossible architecture defying gravity, Escher-like perspectives where ceiling becomes floor
```

## Common Issues and Solutions

### Issue: Style inconsistency
**Solution**: Use cohesive style descriptors throughout, avoid mixing conflicting aesthetics

### Issue: Overworked details
**Solution**: Balance detail distribution, leave breathing room in composition

### Issue: Unclear focal point
**Solution**: Explicitly state primary focus, use lighting and blur to guide eye

### Issue: Flat emotional impact
**Solution**: Layer mood descriptors, use color psychology, add narrative elements

### Issue: Generic output
**Solution**: Add unique creative modifiers, unexpected combinations, specific artistic references

## Best Practices

### Do's
- ✅ Build prompts in layers from core to details
- ✅ Maintain stylistic coherence throughout
- ✅ Use creative and unexpected combinations
- ✅ Include emotional and atmospheric descriptors
- ✅ Specify technical quality clearly

### Don'ts
- ❌ Mix incompatible art styles
- ❌ Overload with contradictory instructions
- ❌ Neglect compositional balance
- ❌ Forget atmospheric elements
- ❌ Use generic quality tags without context

## Optimization Tips

1. **Layer complexity gradually** - Start simple, add details
2. **Test style combinations** - Find what works together
3. **Use reference artists sparingly** - As influence, not copy
4. **Balance all elements** - No single aspect should dominate
5. **Include unexpected elements** - Surprise creates interest
6. **Maintain thematic coherence** - All parts should feel unified
7. **Specify rendering intent** - Be clear about final look

## Creative Exercises

1. **Style fusion challenge**: Combine two opposing art styles
2. **Mood journey**: Create emotional progression in single image
3. **Impossible physics**: Design believable impossibilities
4. **Time compression**: Show multiple time periods simultaneously
5. **Sensory translation**: Visualize sound, taste, or touch
